# AI Companion Updater

This repository is used exclusively for distributing update artifacts for the AI Companion desktop application.

It contains:

* `latest.json`
* signed updater bundles
* `.sig` signature files

These files are automatically uploaded via GitHub Actions from the private main repository during each release.

## Purpose

The main application source code repository is private.

Tauri's updater requires publicly accessible update files, so this repository acts as the public distribution endpoint for desktop application updates.

## Security

All update packages are cryptographically signed using Tauri updater signing keys.

The desktop application verifies update signatures before installation to ensure authenticity and integrity.

No source code is stored in this repository.

## Auto Update Endpoint

The application fetches updates from:

```txt
https://github.com/<USERNAME>/AI-Companion-Updater/releases/latest/download/latest.json
```

## Release Process

Releases are automatically generated by GitHub Actions from the private application repository.

No manual uploads are required.

## Tech Stack

* Tauri Updater
* GitHub Releases
* GitHub Actions

## Notes

This repository is intended only for update distribution and release hosting.
